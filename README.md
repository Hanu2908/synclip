# Synclip

Copy on one device, paste on another. Synclip syncs clipboard text between Android, desktop (Windows / macOS / Linux) and the web through end-to-end encrypted rooms.

- **Quick Room**: join with a 6-character code, QR or link. No account; expires 10 hours after last use.
- **My Devices**: a permanent room for your own devices, linked with email or Google.
- **End-to-end encrypted**: the server relays and stores only ciphertext. A new device gets the room key only after one of your devices approves it with matching emoji.

> Status: in development (milestone M0). Built with Flutter and Supabase as a learning and portfolio project.
